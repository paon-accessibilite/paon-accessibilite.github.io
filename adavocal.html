adaVocal

Écouter le texte sélectionné et dicter directement dans l’application où vous travaillez, depuis une mini-barre Windows que vous pouvez déplacer.

Lire et dicter

Écouter. Sélectionnez un texte, puis cliquez sur le haut-parleur. Un deuxième clic arrête la lecture. Vous pouvez aussi copier le texte, puis choisir Lire le texte copié avec un clic droit sur le bouton.

Dicter. Placez le curseur dans un champ de saisie, puis cliquez sur le microphone pour ouvrir la dictée Windows. Cette fonction nécessite une connexion Internet.

Régler la lecture

L’engrenage permet de choisir la vitesse et la voix. La voix française Siwis fonctionne hors ligne une fois installée. Les voix Windows accessibles à adaVocal figurent aussi dans le menu.

Pour déplacer la barre, maintenez le clic sur son fond, à gauche ou à droite des boutons, puis faites-la glisser.

La première version fonctionne sous Windows. Le portage vers Linux Mint est prévu.
